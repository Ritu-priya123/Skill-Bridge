# Skill-Bridge
A web-based internship preparation tool that examines the abilities of the student, pinpoints their weaknesses, suggests appropriate fields for internships along with projects and a customized plan for learning.
Problem Description:
Students often struggle to choose the right internship domain and identify the skills they are missing. Skill Bridge analyzes their skills against a target domain and provides personalized guidance.
Features:
Student registration, skill and domain selection, skill-gap analysis, internship-readiness score, project recommendations, and personalized learning roadmap.
Concepts Used:
Skill matching, rule-based recommendation, weighted scoring, database management, and basic data analysis.
Technologies:
HTML, CSS, JavaScript for frontend; Python Flask/FastAPI for backend; and MySQL/SQLite for database.
